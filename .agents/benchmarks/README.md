# Benchmark 方案与成绩

研究者首次启用一个 benchmark 时，再建立它自己的目录。

## 确定公平方案

1. **调研配方。** 查阅多篇相关论文，对照官方 baseline 的训练配方和评测协议。
2. **在聊天中定方案。** 列出影响比较的差异及来源，提出哪些条件固定、哪些变量可改，由研究者确认。
3. **后续实验沿用同一方案。** 调整协议须经研究者确认，旧成绩保留原口径。

## 每个 bench 的文件

| 文件 | 内容 |
|---|---|
| `training.md` | 基线、训练配方与预算、选模规则 |
| `evaluation.md` | 评测范围、指标及计分口径 |
| `results.md` | 取得成绩后创建，只列 **版本、成绩** 两列 |
