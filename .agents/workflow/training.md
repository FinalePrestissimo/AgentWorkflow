# 训练

## 启动与交付

- **用 tmux 启动。** 短训、正式训练和续训都在命名会话中直接运行训练进程。只在 tmux 里看日志不算。
- **确认 W&B 在线记录指标。** 正式训练遇到连接问题不能擅自切到 `mode="offline"`。续训沿用原 run，排错短训默认关闭 W&B。
- **稳定启动即可报告。** 默认不需要等到第一个 checkpoint 保存，也不需要等到训练结束。在 [CURRENT](../CURRENT.md) 留下运行位置和接管入口。

【首次使用时确认：W&B 的 `project` 填什么？若需指定 `entity`，一并填写。】

## 配方与资源

按研究者指定的[机器](machines.md#本仓库可用机器)和已确认的 [benchmark 配方](../benchmarks/README.md)训练。W&B run 的 `name` 包含版本、任务和 seed。

优化吞吐时保持已定的 global batch 和更新预算。优先调整每卡 batch 与梯度累积，再利用剩余显存、改善供数，以训练总耗时衡量收益。

## 运行保护与恢复

- 固定运行所用的代码与配置，保留有效权重和完整续训状态。
- 需要中断训练或从头重训时，由研究者决定。
